Sales Guide: Rare Disease: Neuromuscular & Neurodegenerative

Sales team test guide: 7 tests in Rare Disease: Neuromuscular & Neurodegenerative. For each test: what it checks, when doctors use it, the sample, report time, method and how to pitch it. Doctors to meet: Neurologists, paediatric neurologists, paediatricians. Always confirm MRP and code in the Rate Finder.

Doctors to meet
Neurologists, paediatric neurologists, paediatricians
Pitch tip
Testing healthy relatives (e.g. Huntington) needs genetic counselling first.
Spinal Muscular Atrophy (SMN1 / SMN2 Exon 7/8 by MLPA)
What: Counts SMN1 and SMN2 copies.
When: Floppy, weak baby or child: SMA diagnosis.
Sales pitch: "Treatment exists now; early diagnosis matters."
Code PTMP0073 · 15 days · MLPA · EDTA whole blood
DMD / BMD Gene Deletion / Duplication (79 exons MLPA)
What: Deletions and duplications in the dystrophin gene.
When: Boy with frequent falls, big calves, high CK.
Sales pitch: "High CK in a boy: test DMD."
Code PTMP0235 · 15 days · MLPA · EDTA whole blood
Spinocerebellar Ataxia Panel (SCA 1, 2, 3, 6, 7, 12)
What: Repeat expansions in the common SCA genes.
When: Adult with progressive imbalance, especially with family history.
Sales pitch: "Six SCA types in one test."
Code PTMP0081 · 20 days · TP-PCR · EDTA whole blood
SCA Single Type Targeted Confirmation
What: Tests one known SCA type.
When: When the family's SCA type is known in a relative.
Sales pitch: "Targeted and quicker for families."
Code PTMP0082 · 15 days · TP-PCR · EDTA whole blood
Huntington Disease (HTT CAG repeats)
What: Counts HTT CAG repeats.
When: Involuntary movements, behaviour change, family history.
Sales pitch: "Counselling first for healthy relatives."
Code PTMP0110 · 23 days · TP-PCR · EDTA whole blood
Friedreich Ataxia (FXN GAA repeats)
What: Counts FXN GAA repeats.
When: Young-onset ataxia, absent reflexes, scoliosis, heart muscle disease.
Sales pitch: "Young ataxia with a heart problem: think Friedreich."
Code PTMP0079 · 18 days · PCR / fragment · EDTA whole blood
DMPK Repeat Expansion (Myotonic Dystrophy)
What: Counts DMPK repeats.
When: Cannot release grip (myotonia), weakness, early cataract.
Sales pitch: "Grip that will not let go: test DMPK."
Code to confirm in the Rate Finder · ask lab · TP-PCR · EDTA blood
